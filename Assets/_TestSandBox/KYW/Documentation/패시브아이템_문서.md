# 패시브 아이템 시스템 문서

## 개요
패시브 아이템은 사용 아이템과 동일한 방식으로 구현되며, 사용하면 플레이어에게 지속적인 효과를 부여하는 아이템입니다. 들고 있는 상태에서 클릭하면 사용되어 인벤토리에 효과가 저장되고 아이템은 사라집니다.

## 구현 방식

### 1. 기본 구조
- 사용 아이템과 동일한 `IItemInteraction` 인터페이스 구현
- `OnUsePress`에서 효과 적용 후 아이템 제거
- 플레이어 컨트롤러에서 인벤토리 상태에 따라 효과 적용
- 기존 아이템 시스템과 완전히 호환

### 2. 핵심 아이디어
- **일관성**: 기존 사용 아이템과 동일한 구조
- **단순성**: 복잡한 패시브 시스템 없이 기존 시스템 활용
- **확장성**: 새로운 패시브 아이템 추가가 매우 간단

## 패시브 아이템 종류

### 1. 날개 (Wings)
**기능**: 2단 점프 가능

#### 구현 세부사항
- **효과**: 기본 점프 후 추가 점프 1회 가능
- **조건**: 공중에서 점프 키 입력 시
- **제한**: 지면 착지 시 점프 카운트 리셋

#### 패시브 아이템 구현
```csharp
public class Wings : NetworkBehaviour, IItemInteraction
{
    [Networked] private NetworkBool IsHeld { get; set; }
    bool IItemInteraction.IsHeld => IsHeld;

    public void OnUsePress(Vector2 mouseWorldPosition, Vector2 playerPosition)
    {
        // 플레이어에게 날개 효과 부여
        var playerController = FindFirstObjectByType<PlayerController>();
        if (playerController != null)
        {
            playerController.hasWings = true;
        }
        
        // 아이템 제거
        Runner.Despawn(Object);
    }

    public void OnUseHold(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    public void OnUseRelease(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    
    public void OnPickedUp() { IsHeld = true; }
    public void OnReleased() { IsHeld = false; }
    public void ApplyKnockback(Vector2 force, float duration = 0f) { }
}
```

#### 플레이어 컨트롤러 수정
```csharp
public class PlayerController : NetworkBehaviour
{
    [Networked] private NetworkBool hasWings { get; set; }
    [Networked] private int jumpCount { get; set; } = 0;
    

    
    private void HandleJump()
    {
        // 날개 효과: 2단 점프
        int maxJumps = hasWings ? 2 : 1;
        
        if (jumpCount < maxJumps && jumpInput)
        {
            // 점프 실행
            jumpCount++;
        }
    }
    
    private void OnGroundHit()
    {
        // 지면 착지 시 점프 카운트 리셋
        jumpCount = 0;
    }
}
```

### 2. 제트팩 (Jetpack)
**기능**: 점프 후 연료를 소모하며 지속 점프

#### 구현 세부사항
- **연료 시스템**: 최대 연료량과 현재 연료량 관리
- **점프 방식**: 점프 키를 누르고 있으면 연료 소모하며 위로 힘 적용
- **연료 소모**: 점프 키 누른 시간에 비례하여 연료 감소
- **연료 회복**: 지면 착지 시 연료 자동 회복

#### 패시브 아이템 구현
```csharp
public class Jetpack : NetworkBehaviour, IItemInteraction
{
    [Networked] private NetworkBool IsHeld { get; set; }
    bool IItemInteraction.IsHeld => IsHeld;

    public void OnUsePress(Vector2 mouseWorldPosition, Vector2 playerPosition)
    {
        // 플레이어에게 제트팩 효과 부여
        var playerController = FindFirstObjectByType<PlayerController>();
        if (playerController != null)
        {
            playerController.hasJetpack = true;
            playerController.jetpackFuel = 100f;
        }
        
        // 아이템 제거
        Runner.Despawn(Object);
    }

    public void OnUseHold(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    public void OnUseRelease(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    
    public void OnPickedUp() { IsHeld = true; }
    public void OnReleased() { IsHeld = false; }
    public void ApplyKnockback(Vector2 force, float duration = 0f) { }
}
```

#### 플레이어 컨트롤러 수정
```csharp
public class PlayerController : NetworkBehaviour
{
    [Header("Jetpack Settings")]
    [SerializeField] private float maxFuel = 100f;
    [SerializeField] private float fuelConsumptionRate = 20f;
    [SerializeField] private float jetpackForce = 15f;
    
    [Networked] private NetworkBool hasJetpack { get; set; }
    [Networked] private float jetpackFuel { get; set; } = 100f;
    [Networked] private NetworkBool isUsingJetpack { get; set; }
    

    
    public override void FixedUpdateNetwork()
    {
        // 기존 로직...
        
        // 제트팩 효과 처리
        if (hasJetpack) HandleJetpack();
    }
    
    private void HandleJetpack()
    {
        if (jumpInput && !isGrounded && jetpackFuel > 0)
        {
            isUsingJetpack = true;
            rb.AddForce(Vector2.up * jetpackForce, ForceMode2D.Force);
            jetpackFuel -= fuelConsumptionRate * Runner.DeltaTime;
        }
        else
        {
            isUsingJetpack = false;
        }
    }
    
    private void OnGroundHit()
    {
        if (hasJetpack) jetpackFuel = maxFuel;
    }
}
```

#### 연료 시스템
- **최대 연료**: 100 (설정 가능)
- **소모량**: 점프 키 누른 시간 × 소모율
- **회복**: 지면 착지 시 즉시 100% 회복
- **UI 표시**: 연료 게이지 표시 (선택사항)

### 3. 신발 (SpeedShoes)
**기능**: 이동 속도 증가

#### 구현 세부사항
- **속도 증가**: 기본 이동 속도의 1.5배 (설정 가능)
- **적용 방식**: 플레이어의 이동 속도 변수에 직접 적용
- **지속 효과**: 장착 중 계속 유지

#### 패시브 아이템 구현
```csharp
public class SpeedShoes : NetworkBehaviour, IItemInteraction
{
    [Networked] private NetworkBool IsHeld { get; set; }
    bool IItemInteraction.IsHeld => IsHeld;

    public void OnUsePress(Vector2 mouseWorldPosition, Vector2 playerPosition)
    {
        // 플레이어에게 신발 효과 부여
        var playerController = FindFirstObjectByType<PlayerController>();
        if (playerController != null)
        {
            playerController.hasSpeedShoes = true;
        }
        
        // 아이템 제거
        Runner.Despawn(Object);
    }

    public void OnUseHold(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    public void OnUseRelease(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    
    public void OnPickedUp() { IsHeld = true; }
    public void OnReleased() { IsHeld = false; }
    public void ApplyKnockback(Vector2 force, float duration = 0f) { }
}
```

#### 플레이어 컨트롤러 수정
```csharp
public class PlayerController : NetworkBehaviour
{
    [Header("Speed Settings")]
    [SerializeField] private float baseMoveSpeed = 5f;
    [SerializeField] private float speedMultiplier = 1.5f;
    
    [Networked] private NetworkBool hasSpeedShoes { get; set; }
    

    
    private void HandleMovement()
    {
        // 신발 효과: 속도 증가
        float currentSpeed = hasSpeedShoes ? baseMoveSpeed * speedMultiplier : baseMoveSpeed;
        
        // 이동 로직
        float moveInput = GetMoveInput();
        Vector2 velocity = new Vector2(moveInput * currentSpeed, rb.velocity.y);
        rb.velocity = velocity;
    }
}
```

### 4. 미러볼 (MirrorBall)
**기능**: 플레이어 스프라이트 반짝임 효과

#### 구현 세부사항
- **효과**: 스프라이트 렌더러의 머티리얼을 주기적으로 변경
- **반짝임 패턴**: 여러 머티리얼을 순환하며 적용
- **주기**: 0.5초마다 머티리얼 변경
- **머티리얼**: 반짝이는 효과가 있는 머티리얼들

#### 패시브 아이템 구현
```csharp
public class MirrorBall : NetworkBehaviour, IItemInteraction
{
    [Networked] private NetworkBool IsHeld { get; set; }
    bool IItemInteraction.IsHeld => IsHeld;

    public void OnUsePress(Vector2 mouseWorldPosition, Vector2 playerPosition)
    {
        // 플레이어에게 미러볼 효과 부여
        var playerController = FindFirstObjectByType<PlayerController>();
        if (playerController != null)
        {
            playerController.hasMirrorBall = true;
            playerController.sparkleTimer = TickTimer.CreateFromSeconds(Runner, 0.5f);
        }
        
        // 아이템 제거
        Runner.Despawn(Object);
    }

    public void OnUseHold(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    public void OnUseRelease(Vector2 mouseWorldPosition, Vector2 playerPosition) { }
    
    public void OnPickedUp() { IsHeld = true; }
    public void OnReleased() { IsHeld = false; }
    public void ApplyKnockback(Vector2 force, float duration = 0f) { }
}
```

#### 플레이어 컨트롤러 수정
```csharp
public class PlayerController : NetworkBehaviour
{
    [Header("Mirror Ball Settings")]
    [SerializeField] private Material[] sparkleMaterials;
    [SerializeField] private float sparkleInterval = 0.5f;
    
    [Networked] private NetworkBool hasMirrorBall { get; set; }
    [Networked] private TickTimer sparkleTimer { get; set; }
    [Networked] private int currentSparkleIndex { get; set; }
    
    private SpriteRenderer spriteRenderer;
    private Material originalMaterial;
    
    public override void Spawned()
    {
        spriteRenderer = GetComponent<SpriteRenderer>();
        originalMaterial = spriteRenderer.material;
    }
    

    
    public override void FixedUpdateNetwork()
    {
        // 기존 로직...
        
        // 미러볼 효과 처리
        if (hasMirrorBall) HandleMirrorBall();
    }
    
    private void HandleMirrorBall()
    {
        if (sparkleTimer.Expired(Runner))
        {
            currentSparkleIndex = (currentSparkleIndex + 1) % sparkleMaterials.Length;
            spriteRenderer.material = sparkleMaterials[currentSparkleIndex];
            sparkleTimer = TickTimer.CreateFromSeconds(Runner, sparkleInterval);
        }
    }
}
```

## 통합 구현 구조

### 1. 플레이어 컨트롤러 통합 관리
```csharp
public class PlayerController : NetworkBehaviour
{
    // 패시브 아이템 보유 상태
    [Networked] public NetworkBool hasWings { get; set; }
    [Networked] public NetworkBool hasJetpack { get; set; }
    [Networked] public NetworkBool hasSpeedShoes { get; set; }
    [Networked] public NetworkBool hasMirrorBall { get; set; }
    
    // 제트팩 전용 변수
    [Networked] public float jetpackFuel { get; set; } = 100f;
    [Networked] private NetworkBool isUsingJetpack { get; set; }
    
    // 미러볼 전용 변수
    [Networked] public TickTimer sparkleTimer { get; set; }
    [Networked] private int currentSparkleIndex { get; set; }
    
    // 점프 시스템
    [Networked] private int jumpCount { get; set; } = 0;
    
    public override void FixedUpdateNetwork()
    {
        // 기존 이동/점프 로직...
        
        // 패시브 아이템 효과 처리
        if (hasJetpack) HandleJetpack();
        if (hasMirrorBall) HandleMirrorBall();
    }
}
```

### 2. 사용 방법
1. **아이템 획득**: 기존 아이템 픽업 시스템 사용
2. **아이템 사용**: 들고 있는 상태에서 클릭
3. **효과 적용**: 직접 bool 변수 설정으로 효과 부여
4. **아이템 제거**: `Runner.Despawn()`으로 아이템 소멸

## 네트워크 동기화 고려사항

### 1. 상태 동기화
- 모든 패시브 아이템 상태는 `[Networked]` bool 변수로 간단하게 관리
- 복잡한 인터페이스나 개별 스크립트 없이 플레이어 컨트롤러에서 통합 처리

### 2. 성능 최적화
- 불필요한 Update 호출 제거: 아이템이 있을 때만 해당 로직 실행
- 네트워크 부담 최소화: 필요한 상태만 동기화

### 3. 시각적 효과
- 미러볼의 머티리얼 변경은 모든 클라이언트에서 동기화
- 제트팩 사용 시 애니메이션 효과 추가 가능

## UI 시스템 (선택사항)

### 1. 제트팩 연료 게이지
- 현재 연료량을 시각적으로 표시
- 연료 소모 시 게이지 감소 애니메이션

### 2. 패시브 아이템 아이콘
- 장착된 패시브 아이템들을 아이콘으로 표시
- 아이템 효과 활성화 상태 표시

## 성능 최적화

### 1. 업데이트 최적화
- 조건부 실행: `if (hasJetpack) HandleJetpack()` 형태로 불필요한 처리 방지
- 컴포넌트 참조 캐싱: `Spawned()`에서 한 번만 참조 저장

### 2. 메모리 관리
- 머티리얼 변경 시 원본 머티리얼 보존 및 복원
- 불필요한 객체 생성 방지

## 확장성

### 1. 새로운 패시브 아이템 추가
1. **아이템 스크립트 생성**: `IItemInteraction` 구현
2. **플레이어 컨트롤러 수정**: bool 변수와 처리 로직 추가
3. **직접 접근**: 아이템에서 직접 bool 변수 설정

### 2. 아이템 조합 시스템
- 여러 패시브 아이템 효과의 조합 처리
- 아이템 간 상호작용 로직 구현
- 효과 중복/충돌 처리
