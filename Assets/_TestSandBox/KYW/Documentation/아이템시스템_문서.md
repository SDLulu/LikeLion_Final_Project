# 🗡️ 아이템 시스템 문서

## 📋 개요
멀티플레이어 게임을 위한 근접 무기 시스템입니다. Photon Fusion2를 사용하여 네트워크 동기화를 구현했습니다.

## 🏗️ 프리팹 구조

### 곡괭이 프리팹 구조
```
곡괭이 (메인 오브젝트)
├── 컴포넌트:
│   ├── Transform
│   ├── Box Collider 2D (2개) - 기본콜라이더
│   ├── Composite Collider 2D
│   ├── Rigidbody 2D
│   ├── Pickaxe (Script)
│   ├── Network Rigidbody 2D (Script)
│   └── Network Object
├── 곡괭이이미지 (시각적 표현)
├── 어택콜라이더 (공격용 콜라이더)
│   └── 스크립트: AttackCollisionHandler
└── 스피드콜라이더 (속도 기반 공격용)
    └── 스크립트: SpeedCollisionHandler
```

### 구조 설명
- **기본콜라이더**: 부모 오브젝트에 직접 배치 (Box Collider 2D 2개 + Composite Collider 2D)
- **공격콜라이더**: 별도 자식 오브젝트로 분리
- **속도콜라이더**: 별도 자식 오브젝트로 분리

## 🔧 핵심 스크립트

### 1. IItemInteraction (인터페이스)
```csharp
public interface IItemInteraction : IKnockbackable, IHoldable, IUsableItem
{
    // 넉백
    new void ApplyKnockback(Vector2 force, float duration = 0f);

    // 들기
    bool IsHeld { get; }  // 현재 들려있는지 여부
    new void OnPickedUp();
    new void OnReleased();

    // 사용 (클릭 입력 기반)
    new void OnUsePress(Vector2 mouseWorldPosition, Vector2 playerPosition);
    new void OnUseHold(Vector2 mouseWorldPosition, Vector2 playerPosition);
    new void OnUseRelease(Vector2 mouseWorldPosition, Vector2 playerPosition);
}
```

**주요 메서드:**
- **`IsHeld`**: 아이템이 현재 들려있는지 여부 (IsHoldable 대체)
- **`OnPickedUp()`**: 아이템을 집었을 때 호출
- **`OnReleased()`**: 아이템을 놓았을 때 호출
- **`ApplyKnockback()`**: 넉백 힘 적용
- **`OnUsePress()`**: 마우스 클릭 시 호출 (곡괭이 휘두르기 등)
- **`OnUseHold()`**: 마우스 홀드 시 호출 (연속 공격 등)
- **`OnUseRelease()`**: 마우스 릴리즈 시 호출

### 2. Pickaxe.cs (곡괭이 스크립트)
```csharp
public class Pickaxe : NetworkBehaviour, IItemInteraction
{
    [Header("Pickaxe Settings")]
    [SerializeField] private float swingAngle = 90f;
    [SerializeField] private float swingDuration = 0.18f;
    
    [Header("Attack Collision Handler")]
    [SerializeField] private AttackCollisionHandler attackCollisionHandler;
    
    [Networked] private TickTimer PickaxeTimer { get; set; }
    [Networked] private NetworkBool IsHeld { get; set; }
    
    private bool isPickaxeActive => PickaxeTimer.IsRunning;
    bool IItemInteraction.IsHeld => IsHeld;
    
    // 공격 로직, 타이머 관리, 애니메이션 등
}
```

**주요 기능:**
- 곡괭이 휘두르기 애니메이션
- 타이머 기반 공격 지속시간 관리
- 들기/놓기 상태 관리
- AttackCollisionHandler와 연동

### 3. AttackCollisionHandler.cs
**역할**: 아이템 사용 시 충돌 처리

```csharp
public class AttackCollisionHandler : NetworkBehaviour
{
    [Header("Attack Settings")]
    [SerializeField] private int attackDamage = 1;
    [SerializeField] private float knockbackForce = 5f;
    [SerializeField] private float knockbackDuration = 0.5f;
    
    [Header("Collider Reference")]
    [SerializeField] public Collider2D AttackCollider;
    
    private IItemInteraction weaponItem;
}
```

**주요 기능:**
- 공격 콜라이더 활성화 시 충돌 감지
- 플레이어/NPC: 데미지 + 넉백 + 무적시간 적용
- 아이템: 넉백만 적용
- 같은 아이템 내부 충돌 방지 (`IsSameItem()` 메서드)
- 들린 상태에서만 작동 (`IsHeld = true`)

### 4. SpeedCollisionHandler.cs
**역할**: 아이템이 던져지거나 빠르게 움직일 때 충돌 처리

```csharp
public class SpeedCollisionHandler : NetworkBehaviour
{
    [Header("Speed Attack Settings")]
    [SerializeField] private float attackSpeedThreshold = 0.3f;  // 공격 콜라이더 활성화 속도 임계값
    [SerializeField] private float normalSpeedThreshold = 0.05f;  // 일반 콜라이더로 되돌릴 속도 임계값
    
    [Header("Collision Settings")]
    [SerializeField] private int speedAttackDamage = 1;
    [SerializeField] private float speedAttackKnockbackForce = 5f;
    [SerializeField] private float speedAttackKnockbackDuration = 0.5f;
    
    [Header("Collider References")]
    [SerializeField] private Collider2D speedAttackCollider;    // SpeedAttack 레이어 콜라이더
    
    [Networked] private NetworkBool IsInSpeedAttackMode { get; set; }
}
```

**주요 기능:**
- 속도 임계값에 따른 콜라이더 자동 활성화/비활성화
- 들리지 않은 상태에서만 작동 (`IsHeld = false`)
- 충돌 시 데미지 + 넉백 적용
- 같은 아이템 내부 충돌 방지 (`IsSameItem()` 메서드)
- 부모 오브젝트의 Rigidbody2D 속도 체크

## ⚡ 작동 방식

### 1. 곡괭이 사용 (AttackCollisionHandler)
```
1. 플레이어가 곡괭이 집기 → IsHeld = true
2. 마우스 클릭 → PickaxeTimer 시작
3. 어택콜라이더 활성화 → AttackCollisionHandler 작동
4. 충돌 감지 시:
   - 플레이어/NPC: 데미지 + 넉백 + 무적시간
   - 아이템: 넉백만
   - 같은 아이템 내부: 무시
5. 타이머 종료 → 어택콜라이더 비활성화
```

### 2. 곡괭이 던지기 (SpeedCollisionHandler)
```
1. 플레이어가 곡괭이 놓기 → IsHeld = false
2. 곡괭이가 빠르게 움직임 → 속도 ≥ 0.3f
3. 스피드콜라이더 활성화 → SpeedCollisionHandler 작동
4. 충돌 시 데미지 + 넉백 (같은 아이템 내부 충돌 방지)
5. 속도 감소 → 속도 ≤ 0.05f
6. 스피드콜라이더 비활성화
```

### 3. 상태 관리
```
IsHeld = true  → 아이템이 들린 상태
IsHeld = false → 아이템이 바닥에 있는 상태

기존 IsHoldable은 IsHeld로 통합
- 들린 상태: IsHeld = true (들 수 없음)
- 바닥 상태: IsHeld = false (들 수 있음)
```

## 🔗 인스펙터 연결

### 필수 연결 작업:
1. **AttackCollisionHandler** → `Attack Collider` 필드에 어택콜라이더의 `Collider2D` 연결
2. **SpeedCollisionHandler** → `Speed Attack Collider` 필드에 스피드콜라이더의 `Collider2D` 연결
3. **Pickaxe** → `Attack Collision Handler` 필드에 어택콜라이더의 `AttackCollisionHandler` 스크립트 연결

### 연결 방법:
- 인스펙터에서 해당 필드에 드래그 앤 드롭으로 연결
- 프리팹 구조가 일정하므로 한 번 설정하면 재사용 가능

## 🛡️ 안전장치

### 1. 자기 자신 맞기 방지
```csharp
private bool IsSameItem(GameObject other)
{
    // 자기 자신
    if (other == gameObject) return true;
    
    // 부모가 같은지 확인 (같은 아이템의 다른 콜라이더)
    if (weaponItem != null)
    {
        var otherItem = other.GetComponentInParent<IItemInteraction>();
        if (otherItem != null && otherItem == weaponItem) return true;
    }
    
    // 자식인지 확인
    if (other.transform.IsChildOf(transform)) return true;
    
    // 부모인지 확인
    if (transform.IsChildOf(other.transform)) return true;
    
    return false;
}
```

### 2. 무적 상태 보호
```csharp
// PlayerInteractionBase에서 무적 상태일 때 보호
if (stunInvincible?.IsInvincible == true) return;
```

### 3. 권한 체크
```csharp
if (!HasStateAuthority) return;  // StateAuthority만 처리
```

### 4. 넉백 방향 계산
```csharp
// 콜라이더의 실제 중심점을 기준으로 정확한 방향 계산
Vector2 knockbackDirection = ((Vector2)target.transform.position - (Vector2)AttackCollider.bounds.center).normalized;
```

## 📝 주의사항

1. **네트워크 동기화**: 모든 상태 변경은 `[Networked]` 프로퍼티 사용
2. **권한 체크**: `HasStateAuthority` 확인 필수
3. **타이머 사용**: `TickTimer`로 시간 기반 로직 구현
4. **콜라이더 연결**: 인스펙터에서 수동 연결 필요
5. **충돌 레이어**: 적절한 레이어 설정으로 충돌 제어
6. **부모 해제 지연**: 아이템 던질 때 부모 해제가 0.05초 지연되어 자기 자신과의 충돌 방지
